# CSS 배틀

**CSS 선택자와 캐스케이드를 "타이핑 · 진단 · 재현" 세 가지 훈련으로 몸에 익히는 학습용 웹 페이지입니다.**

회원가입도, 설치도 필요 없습니다. 브라우저로 열면 바로 시작할 수 있고, 학습 기록은 그 브라우저(localStorage)에만 저장됩니다.

---

## 왜 만들었나

CSS는 글로 설명하면 추상적입니다. 그래서

- 입문자는 원리를 모른 채 `!important`로 땜빵하고,
- 실무자도 스타일이 충돌하면 개발자도구를 한참 뒤지며 "감"으로 고칩니다.

"분명 스타일 줬는데 왜 안 먹히지?" 이 상황을 **직접 부딪혀서** 넘기도록 만든 페이지입니다.
개념 설명을 읽는 대신, 손으로 쳐보고 · 버그를 스스로 진단하고 · 시안을 직접 재현하며 반복합니다.

## 누구를 위한 것

- CSS 우선순위가 감으로만 잡히는 **입문 · 주니어**
- 스타일 충돌 디버깅에 시간을 쓰는 **현직 개발자**
- 막히면 바로 AI에 붙여넣고 원리는 모르고 넘어가는 사람

---

## 무엇을 할 수 있나

전체는 4개의 모드로 이루어져 있고, 앞의 3개가 학습 단계입니다.

### 1. 타자연습 — 손에 익히기
화면에 나온 CSS 선택자를 그대로, 빠르고 정확하게 타이핑합니다.
조합자(`>`, `+`), 속성 선택자, 의사클래스 같은 **복합 선택자**만 출제되고,
문제마다 "이 선택자가 무엇을 고르는지" 한 줄 설명이 붙습니다.
글자 단위로 맞음/틀림이 실시간 표시되고, 정확히 맞아야 다음으로 넘어갑니다.

### 2. CSS 디버그 — 원리 잡기
앱이 현실적인 CSS 버그 상황을 **출제**합니다.
"이 요소가 흰색이어야 하는데 회색으로 나온다 — 왜인가?"
→ 원인을 고르고 → `!important` 없이 **가장 작은 수정**으로 직접 고쳐서 검증합니다.
캐스케이드(어느 규칙이 이기나), 쌓임 맥락 · overflow · 마진 상쇄 같은 "적용은 됐는데 효과가 안 나는" 경우, 상속까지 다룹니다.
개발자도구는 "무엇이 이겼나"까지만 알려주지만, 이 모드는 **원인을 짚는 연습**을 시킵니다.

### 3. 배틀 — 실전 재현
완성된 디자인 **시안**과 스타일이 거의 없는 **HTML**이 주어집니다.
시안과 똑같이 보이도록 **CSS를 0부터** 작성합니다. (HTML은 수정 불가)

- 시안 위에 내 결과를 **겹쳐보기**(투명도 슬라이더)로 눈으로 맞춤
- 시안에서 **색 추출**(스와치 팔레트 · 스포이드)
- **예시 정답**을 한 줄씩 힌트로 공개
- 완료 시 **셀렉터 위생 체크리스트**(`!important` 없이 해결 / ID 선택자 미사용 / 3단계 이하 …)

정답이 하나가 아니라서 **점수는 매기지 않습니다.** 스스로 확인하는 도구입니다.
"배틀"은 사람 대 사람이 아니라 **디자인 시안과의 1:1**(= 모작 연습)이라는 뜻입니다.

### 4. 퀘스트 / 스탬프 / 마이페이지 — 다시 오게 만드는 장치
- **오늘의 퀘스트** 3개(배틀 · 타자 · 디버그) — 목표치는 날짜마다 조금씩 바뀝니다
- **연속 출석 스트릭** — 하루 한 번 접속하면 이어지고, 하루 비면 0부터
- **스탬프 카드** — 한 달 달력. 퀘스트 3개를 모두 깬 날에 스탬프(★)
- **마이페이지** — 모은 스탬프로 칭호 획득(3 · 7 · 14 · 30개). 보상은 칭호 표시가 전부입니다

## 디자인 톤

8bit 아케이드 격투게임 느낌 — 로고 · STAGE 라벨 · FIGHT 버튼 등 임팩트가 필요한 곳엔 픽셀 폰트(`Press Start 2P`)를, 본문과 코드 영역은 `Pretendard`로 읽기 편하게. 어두운 보라 배경에 시안/마젠타/골드 포인트 컬러.

## 기술

프레임워크 · 번들러 없이 **순수 HTML / CSS / 바닐라 JS(ES Modules)**. 상태는 단일 `store` 객체 + localStorage. 정답 검증은 iframe에 렌더 후 `getComputedStyle` / `getBoundingClientRect` 같은 브라우저 네이티브 API로 처리합니다. 서버 · DB · 외부 API 없이 프론트엔드로 완결됩니다.
